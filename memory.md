## Design preferences

- Demo sites represent the VIGNO Essential package: one page, mobile-first, contact
  form, prominent booking CTA, map link. The demo is the product the prospect keeps.
- Build to VIGNO's stated standard: custom design per business, never template
  energy; bookings/forms treated as first-class, not an afterthought.
- Bilingual-ready structure (lang attribute correct, copy easy to translate);
  default French for Québec businesses, English elsewhere, mirror the business's
  own language when it's clear from their reviews.
